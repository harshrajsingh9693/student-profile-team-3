# 🎓 Student Profile Repository

A collaborative-style Web Development project demonstrating the fundamentals of **Git and GitHub** through a student profile website.

This project was developed as part of a Web Development Lab to practise repository management, branching, commits, pushing changes, pull requests and merging feature branches into the `main` branch.

---

## 📌 Project Overview

The **Student Profile Repository** contains three individual HTML pages that present a student's personal profile, technical skills and contact information.

The project also demonstrates a structured Git workflow in which separate features are developed on individual branches and integrated into the main branch using Pull Requests.

## 🎯 Objectives

- Understand Git and GitHub fundamentals.
- Create and manage a public GitHub repository.
- Practise cloning a repository.
- Create and switch between feature branches.
- Add, commit and push files.
- Create and merge Pull Requests.
- Understand the importance of version control.
- Organise a basic multi-page HTML project.

## 🌿 Git Branching Strategy

Each feature was developed using a separate Git branch.

| Branch            | File           | Purpose              | Status    |
| ----------------- | -------------- | -------------------- | --------- |
| `main`            | `README.md`    | Main project branch  | Completed |
| `feature/profile` | `profile.html` | Student profile page | Merged    |
| `feature/skills`  | `skills.html`  | Student skills page  | Merged    |
| `feature/contact` | `contact.html` | Student contact page | Merged    |

## 🔄 Git Workflow

The following Git commands were used during development:

**1. Clone the repository**

```bash
git clone https://github.com/harshrajsingh9693/student-profile-team-3.git
```

**2. Navigate to the project**

```bash
cd student-profile-team-3
```

**3. Create a feature branch**

```bash
git switch -c feature/profile
```

**4. Add files to staging**

```bash
git add profile.html
```

**5. Commit changes**

```bash
git commit -m "Add student profile page"
```

**6. Push the branch**

```bash
git push -u origin feature/profile
```

**7. Create a Pull Request**

Open GitHub, compare the feature branch with `main`, and create a Pull Request.

**8. Merge the Pull Request**

After reviewing the changes, merge the approved Pull Request into `main`.

The same process was followed for the skills and contact pages.
